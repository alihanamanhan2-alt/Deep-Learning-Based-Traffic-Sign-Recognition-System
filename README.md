# Терең оқыту әдістеріне негізделген жол белгілерін тану жүйесі

Бұл жүйе компьютерлік көру және терең оқыту әдістерін пайдаланып жол белгілерінің суреттерін таниды.

## Мүмкіндіктер

- CNN архитектурасымен модельді оқыту;
- сурет жүктеп тану;
- бейне кадрларынан тану;
- мобильді немесе камерадан алынған суретке тестілеу;
- оқу нәтижелерінің графиктері;
- Streamlit арқылы графикалық интерфейс.

## Жылдам іске қосу

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python train.py
streamlit run app.py
```

## Деректер жиыны

Деректер жиынының құрылымы:

```text
data/
  Train/
    0/
    1/
    ...
  Test/
  Meta/
  Train.csv
  Test.csv
```

GTSRB деректер жиынын жүктеп, ZIP-файлдан алынған `Train`, `Test`, `Meta`, `Train.csv` және `Test.csv` каталогтарын `data/` ішіне орналастырыңыз.

## Негізгі файлдар

- `train.py` — модельді үйретеді;
- `predict.py` — бір сурет бойынша болжам жасайды;
- `app.py` — Streamlit веб-интерфейсі;
- `test_model.py` — модельдің сапасын тексереді;
- `COURSEWORK.md` — қазақ тіліндегі курстық жұмыс мәтіні;
